# Pick Activity — The if/else Program

**Live:** https://professor-jeff.github.io/pick-activity-rules/

Part 1 of the COMP 138 neural network demo series. A single-file page that shows
the Python if/else program that picks an activity from a temperature and a chance
of rain. Two sliders stand in for the `input()` prompts; the page lights up the
branch that runs, shows what the program prints, and explains why.

Part 2, https://professor-jeff.github.io/pick-activity/, trains a neural network
to discover these same rules from examples.

## Deploying

Edit `index.html` and push to `main`. GitHub Pages redeploys within about a minute.
