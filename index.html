Pick Activity: the if/else program

Two numbers in, one answer out. The sliders stand in for typing at the two input() prompts. Slide them and watch which branch of the program runs.

The rules

A person decided these five rules and typed them into the program below. The highlighted row is where the sliders land right now; the program reaches the same answer by checking the rules one line at a time, in order.

Inputs

The program prints

What is the chance of rain, 0-100? 20
What is the temperature? 72
Go Running

In the real program, input() stops and waits for you to type a number. int() turns what you typed into a whole number so it can be compared with >= and <.

The Python program

rain = int(input("What is the chance of rain, 0-100? " ))
temp = int(input("What is the temperature? " ))
if temp >= 80 and rain < 50 :
  print("Play VolleyBall" )
elif temp >= 80 and rain >= 50 :
  print("See a Movie" )
elif temp >= 32 and temp < 80 and rain < 50 :
  print("Go Running" )
elif temp >= 32 and temp < 80 and rain >= 50 :
  print("Try Yoga" )
else:
  print("Read a Book" )

Python reads the conditions from the top and runs the first one that is True. Everything after it is skipped without being checked. If none are True, the else runs.

Every rule on this page was typed by a person who already knew the answer. On the next page the computer is given only examples, a temperature, a chance of rain, and what this program printed, and has to discover the rules on its own. Try sliding to exactly 80°, exactly 32°, or exactly 50% rain and watch which branch flips.

Key points

  1. This is ordinary programming: a person wrote every rule. Two numbers in, one of five answers out.
  2. Python checks the conditions top to bottom and runs the first one that is True. Everything below it is skipped unread.
  3. The table and the code are the same five rules written two ways, so the highlighted row and the lit branch always agree.
  4. It is never wrong, and it never learns. Change the rules and a human has to retype them. The next page gives a computer only examples.
